# 原神 聖遺物・武器最適化ツール

武器 × 聖遺物セット × メインステータスを総当たりし、
各組み合わせで最適なサブステ割り振りを探索してキャラ別に表示します。

公開ページ: https://rubemarin.github.io/genshin-artifact-optimizer/

## 対応キャラ
- ナヒーダ(順次追加予定)

## 使い方
- ベース可変ロール数、チャージロール数を入れて「計算」
- 行をクリックすると上位10件の組み合わせを表示

## キャラの追加
`characters/` に `キャラ名.js` を追加し、`index.html` に `<script>` を1行足します。

## 注意
非公式のファンツールです。ゲーム内の名称・画像の権利は HoYoverse (miHoYo) に帰属します。
